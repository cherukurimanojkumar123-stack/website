2.Write a PHP program to display Fibonacci series. Program:
<?php
$n = 10;
$a = 0;
$b = 1;
echo "Fibonacci Series of $n terms:<br>"; echo $a . " " . $b . " ";
for ($i = 3; $i <= $n; $i++) {
$c = $a + $b; echo $c . " ";
$a = $b;
$b = $c;
}
?>

5.Write a PHP program to generate the multiplication of two matrices. Program:
<?php
$a = array( array(1, 2),
array(3, 4)
);
$b = array( array(5, 6),
array(7, 8)
);
$result = array( array(0, 0),
array(0, 0)
);
for ($i = 0; $i < 2; $i++) { for ($j = 0; $j < 2; $j++) {
for ($k = 0; $k < 2; $k++) {
$result[$i][$j] += $a[$i][$k] * $b[$k][$j];
}
}
}

echo "Resultant Matrix:<br>";
for ($i = 0; $i < 2; $i++) { for ($j = 0; $j < 2; $j++) {
echo $result[$i][$j] . " ";
}
echo "<br>";
}
?>

9.Write a program to keep track of how many times a visitor has loaded the page. Program:
<?php
if (isset($_COOKIE['counter'])) {
$count = $_COOKIE['counter'] + 1;
} else {
$count = 1;
}
setcookie("counter", $count, time() + 3600);
echo "You have visited this page " . $count . " times.";
?>
